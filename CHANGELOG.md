# Changelog

All notable published changes to Discord Fex are documented here.

## [9.3.0] - 2026-10-05

### Included

- Ready-made zapret/WinDivert presets for Discord, YouTube, and combined use.
- Alternative and ISP-specific configurations.
- Discord voice traffic support.
- Windows service installation and management through `service.bat`.
- Automatic preset discovery and `blockcheck` diagnostics.
- Game mode, domain-list management, and network testing tools.
- Archived presets from previous bundle versions.

### Repository

- Added complete English documentation.
- Added security guidance and third-party attribution.
- Added Git settings for Windows and Cygwin line endings.
- Published a versioned Windows ZIP bundle with a SHA-256 checksum.
